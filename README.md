# ShrijiLang 🌸

Beginner-friendly programming language project focused on making coding easier to understand and thoda kam darawna for new learners.

---

# Why ShrijiLang?

Bahut log coding shuru karna chahte hain.

Lekin:

- English syntax confusing lagti hai
- error messages samajh nahi aate
- beginners ko judge kiya jata hai
- coding bahut heavy feel hoti hai

ShrijiLang ka goal coding ko thoda easier aur beginner-friendly banana hai.

Yeh project specially un logon ke liye hai jo coding se darte hain ya start karne me uncomfortable feel karte hain.
